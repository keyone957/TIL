### 빌드

> 소스 코드를 실행 가능한 프로그램 (기계가 실행할 수 있는 형태)으로 변환하는 과정 전체를 의미

### 빌드 과정에서 일어나는 핵심 단계

#### 컴파일

> 개발자가 작성한 프로그래밍 언어를 컴퓨터가 이해할 수 있는 기계어나 중간 언어 로 번역함

#### 링킹

> 프로그램 구동에 필요한 여러 코드 파일과 외부 라이브러리, 모듈들의 주소를 서로 연결하여 하나의 온전한 실행 단위를 만듦

#### 패키징

> 실행 파일 이나 배포 가능한 형태로 묶음

ex) apk,exe 파일

</aside>

### 부동 소수점

<aside>

### 부동소수점

> 실수를 컴퓨터에서 근사적으로 표현하기 위한 방법

### 부동 소수점 오차

> 0.1 처럼 10진수에서는 간단히 끝나는 소수도 컴퓨터의 2진수 체계로 변환하면 무한 소수가 되는 경우가 많음. 컴퓨터는 이 무한 소수를 정해진 비트 안에 잘라서 저장해야하므로 아주 미세한 오차가 발생한 근사값으로 저장됨. 이 미세한 오차 때문에 연산결과가 컴퓨터 내부에서는 다를 수 있음.

EX) 0.1+0.2=0.3 ⇒ 0.3자체는 저장될 때 0.299999 와 같은 근사값으로 저장될 수 있음

따라서 만약에 저 수를 == 으로 비교 한다면 TRUE가 아닌 FALSE가 나올 수 있다

</aside>
